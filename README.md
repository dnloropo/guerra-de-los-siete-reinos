# Guerra de los Siete Reinos

RPG web 3D jugable en el navegador: explora un mundo abierto a pie, reta a los clanes rivales a batallas por turnos y únelos bajo una sola bandera.

Construido con [Three.js](https://threejs.org/) en un único archivo HTML autocontenido (sin build step, sin dependencias externas en tiempo de ejecución).

## Jugar

🎮 **Jugar en vivo:** https://guerra-de-los-siete-reinos.vercel.app

O simplemente abre `index.html` en un navegador moderno.

## Controles

- **WASD / flechas** — moverse
- **Arrastrar sobre la pantalla** — rotar la cámara en tercera persona
- Acércate al territorio de un clan para iniciar un reto por turnos
